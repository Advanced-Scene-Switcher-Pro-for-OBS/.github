## 🚀 What It Is
Advanced Scene Switcher Pro for Windows is a friendly little plugin that lives inside OBS Studio and handles scene changes so you don't have to. You describe what should happen — "when this game is running, show the gameplay scene" — and the advanced scene switcher watches for that condition and does the switch. If you have ever wished OBS could react to what is happening on your PC, this OBS advanced scene switcher is exactly that.

## ✨ Key Features
> Build automation from simple, readable conditions — no scripting required.

- 🪟 **Window and process triggers** — Switch scenes when a chosen app, game, or window becomes active.
- 🧩 **Macro builder** — Combine multiple conditions and actions into one automated rule.
- ⏱️ **Timers and schedules** — React to idle time, the clock, or a set interval.
- 🎚️ **Media and audio awareness** — Respond to playback state and audio activity.
- 🆓 **Completely free** — An open-source plugin you can use and share at no cost.

## 📥 Setup
1. Use the **Download** button above to grab the free Advanced Scene Switcher OBS plugin download for Windows.
2. Quit OBS Studio and run the installer (or place the plugin into the OBS Studio plugins directory) as prompted.
3. Reopen OBS Studio and choose **Tools → Advanced Scene Switcher** to find the add-on ready to configure.

## 🎯 First Steps
1. Open OBS Studio with the scene collection you normally stream or record with.
2. From the menu bar, pick **Tools → Advanced Scene Switcher**.
3. Add a condition (such as a running application) and match it to a target scene.
4. Turn the switcher on and try it — the scene should change on its own when the condition happens.
